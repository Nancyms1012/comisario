# Comisario Principal

App para organizar las tareas del **comisario principal** en eventos de ciclismo (de uno o varios días).

- **App principal (edición):** `/` (`index.html`)
- **Vista de consulta del equipo (solo lectura):** `/ver.html`

Cloudflare Worker + Workers KV. Sin login. En español.

Ver [HANDOFF.md](./HANDOFF.md) para detalles de arquitectura y deploy.
